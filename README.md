## Introduction
This repository contains the tasks completed for Lab 03 of the Programming Fundamentals course. It covers using GitHub for version control (branches, commits, pull requests) as well as core C programming concepts such as data types, format specifiers, and input/output functions.

1. Learn how to create and configure a GitHub repository.

- Input/output functions (scanf, printf, getchar, putchar, fgets, puts)
